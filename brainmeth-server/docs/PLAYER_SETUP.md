# Player setup

The intended player experience is:

1. Open the Modrinth App.
2. Create a normal **NeoForge 26.2** instance.
3. Install **AutoModpack** into that instance once.
4. Connect to Brainmeth.
5. Verify/accept the server fingerprint and official pack download.
6. Let AutoModpack synchronise the Brainmeth files.
7. Restart when prompted.
8. Play.

Afterwards, AutoModpack keeps official Brainmeth content in sync. Players may add their own genuinely client-side extras through Modrinth, provided they do not deliberately install conflicting alternate versions of Brainmeth-managed mods.
